## Overview

This project is a basic HTML assignment demonstrating the use of fundamental HTML tags including text formatting, lists, and anchor tags across two linked web pages.

---

## Files

| File | Description |
|------|-------------|
| `assignment.html` | Main page covering all 5 assignment tasks |
| `about.html` | Secondary page linked from the main page |

---

## Tasks Completed

### Task 1 – Headings and Paragraph
- `<h1>` tag used for the student's name
- `<h2>` tag used for the "About Me" subheading
- `<p>` tag used for a personal introduction paragraph

### Task 2 – Text Formatting
A hobby paragraph demonstrating:
- `<b>` – bold text
- `<strong>` – important text
- `<i>` – italic text
- `<em>` – emphasized text
- `<u>` – underlined text
- `<mark>` – highlighted text
- `<br>` – line break

### Task 3 – Lists
- **Unordered list** (`<ul>` / `<li>`) — 5 favorite foods
- **Ordered list** (`<ol>` / `<li>`) — steps to start a computer

### Task 4 – Anchor Tags
- Link to [Google](https://www.google.com)
- Link to [YouTube](https://www.youtube.com)
- Link to [GitHub](https://www.github.com) — opens in a new tab (`target="_blank"`)

### Task 5 – File Navigation
- `assignment.html` links to `about.html`
- `about.html` links back to `assignment.html`

---

## How to Run

1. Download and unzip the project folder.
2. Make sure both `assignment.html` and `about.html` are in the **same folder**.
3. Open `assignment.html` in any web browser.
4. Use the navigation link at the bottom to visit `about.html`.
